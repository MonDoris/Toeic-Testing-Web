## 1. Công thức

| Loại | Tính từ ngắn | Tính từ dài |
|---|---|---|
| So sánh hơn | cheap**er than** | **more** convenient **than** |
| So sánh nhất | **the** cheap**est** | **the most** convenient |
| So sánh bằng | **as** cheap **as** | **as** convenient **as** |

**Bất quy tắc:** good → better → best · bad → worse → worst · far → farther/further · many/much → more → most · little → less → least

## 2. Nhấn mạnh
- So sánh hơn: **much / far / significantly / a lot** + so sánh hơn
  *Working from home is **much more flexible than** commuting.*
- So sánh nhất: **by far** the best
