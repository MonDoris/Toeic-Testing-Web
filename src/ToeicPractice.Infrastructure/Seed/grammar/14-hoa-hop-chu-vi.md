## 1. Nguyên tắc cơ bản
- *The manager **reviews** each report.* / *The managers **review** each report.*

## 2. Các trường hợp dễ nhầm

| Chủ ngữ | Động từ | Ví dụ |
|---|---|---|
| **Each / Every / Either / Neither** + N | số ít | **Each** employee **has** a locker. |
| **One of** + N số nhiều | số ít | **One of** the printers **is** broken. |
| **A number of** + N | số nhiều | **A number of** guests **have** arrived. |
| **The number of** + N | số ít | **The number of** applicants **is** increasing. |
| N1 **with / along with / as well as** N2 | theo N1 | The CEO, **along with** his assistants, **is** traveling. |
| V-ing / To V làm chủ ngữ | số ít | **Reading** reviews **helps** customers decide. |
| Danh từ không đếm được | số ít | The **information** **is** on the website. |
| **There is / There are** | theo danh từ phía sau | **There are** two chairs next to the desk. |

## 3. Danh từ không đếm được hay gặp trong TOEIC
**information, equipment, furniture, luggage, baggage, advice, feedback, research, machinery, merchandise, staff (thường số nhiều trong Anh-Mỹ)**
